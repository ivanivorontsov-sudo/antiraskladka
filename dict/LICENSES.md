# Источники словарей опечаток

Файлы `src/Core/Dict/ru.txt.gz` и `src/Core/Dict/en.txt.gz` собраны скриптом `tools/build_dict.py` из:

| Источник | Что взято | Лицензия |
|---|---|---|
| Hunspell **ru_RU** (А. И. Лебедев, словарь LibreOffice, пакет `hunspell-ru` 25.2) | все словоформы (`unmunch`), ~1,3 млн | BSD-подобная лицензия автора (модифицированная BSD) |
| Hunspell **en_US** (SCOWL / Kevin Atkinson, словарь LibreOffice, пакет `hunspell-en-us`) | все словоформы | лицензия SCOWL (MIT/BSD-подобная) |
| **wordfreq** 3.x (Robyn Speer) — частоты слов из Википедии, субтитров, новостей, Reddit, Twitter и др. | частоты (zipf) и разговорные/сленговые/редкие слова, которых нет в Hunspell (zipf ≥ 1.8, без частых опечаток) | данные CC BY-SA 4.0, код Apache 2.0 |
| `dict/curated/*.txt` | профессиональные термины (IT, медицина, право, инженерия, финансы) и сленг | CC0, составлены для этого проекта |

Поскольку частоты wordfreq распространяются по CC BY-SA 4.0, производные файлы словарей
(`src/Core/Dict/*.txt.gz`) распространяются на тех же условиях (CC BY-SA 4.0) с указанием источников выше.
Код программы на эти условия не влияет.
