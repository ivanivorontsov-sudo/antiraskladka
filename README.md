# Антираскладка 1.0.0

Утилита для Windows: выделите текст, набранный не в той раскладке («ghbdtn» → «привет», «руддщ» → «hello»), и нажмите **Pause/Break**, **Ctrl+Shift+Q** или кнопку «Сменить раскладку», которая появляется рядом с курсором после выделения мышью.

- Перевод по положению клавиш, включая все символы с Shift (`!@#$%^&*` ↔ `!"№;%:?*`, `` ` ~ `` ↔ `ё Ё`, `[ ] { } ; ' : " , . < > / ? \ |`).
- Направление определяется автоматически.
- Раскладки: «Авто из Windows» (по умолчанию, через GetKeyboardLayoutList + ToUnicodeEx), США QWERTY, Великобритания, Дворак, Colemak; русская ЙЦУКЕН, машинопись, фонетическая ЯВЕРТЫ, украинская, белорусская.
- После замены возвращает буфер обмена и переключает язык ввода.
- Значок в трее, автозапуск, установщик без прав администратора.

Сборка: `dotnet test tests && dotnet publish src/App -c Release -o out && makensis installer/antiraskladka.nsi`
