# Антираскладка 1.1.0

Утилита для Windows: выделите текст, набранный не в той раскладке («ghbdtn» → «привет», «руддщ» → «hello»), и нажмите **Pause/Break**, **Ctrl+Shift+Q** или кнопку «Сменить раскладку», которая появляется рядом с курсором после выделения мышью.

- Перевод по положению клавиш, включая все символы с Shift (`!@#$%^&*` ↔ `!"№;%:?*`, `` ` ~ `` ↔ `ё Ё`, `[ ] { } ; ' : " , . < > / ? \ |`).
- Направление определяется автоматически.
- Раскладки: «Авто из Windows» (по умолчанию, через GetKeyboardLayoutList + ToUnicodeEx), США QWERTY, Великобритания, Дворак, Colemak; русская ЙЦУКЕН, машинопись, фонетическая ЯВЕРТЫ, украинская, белорусская.
- После замены возвращает буфер обмена и переключает язык ввода.
- Значок в трее, автозапуск, установщик без прав администратора.

## Исправление опечаток (новое в 1.1)

Та же горячая клавиша теперь исправляет и опечатки — на русском и английском:

- «превет мир» → «привет мир», «recieve» → «receive» (текст уже в правильной раскладке — меняются только опечатки);
- «ghtdtn» → «привет» (чужая раскладка **и** опечатка — сначала перевод, потом исправление);
- корректный текст («привет») переводится в другую раскладку, как и раньше.

Словарь — около 1,3 млн русских словоформ (все падежи, времена, формы глаголов) и ~185 тыс. английских: общеупотребительные и редкие слова,
профессиональные термины (IT, медицина, право, инженерия, финансы) и сленг («кринж», «задеплоить», «rizz», «lowkey»). Источники и лицензии — в [dict/LICENSES.md](dict/LICENSES.md).

Как работает: для неизвестного слова перебираются варианты на расстоянии Дамерау—Левенштейна 1 (для слов от 6 букв — 2):
пропуск, лишняя буква, замена, перестановка соседних. Варианты ранжируются по частоте слова и «правдоподобию» ошибки
(соседние клавиши, пропущенная двойная буква, е/ё/и, а/о и т. п.). Регистр сохраняется («Превет» → «Привет»).

Что **не** исправляется: известные слова; слова короче 4 букв; СЛОВА ЗАГЛАВНЫМИ; слова с заглавной внутри предложения (имена, названия);
идентификаторы кода (`camelCase`, `snake_case`, слова с цифрами), ссылки, почта, пути к файлам, ключи командной строки.

Меню в трее:
- «Только исправить опечатки в выделенном» — без смены раскладки;
- «Добавить выделенное слово в словарь» — слово считается правильным и предлагается при исправлении;
- «Никогда не исправлять выделенное слово».

Личный словарь — обычные текстовые файлы `%APPDATA%\Antiraskladka\мои_слова.txt` и `игнор.txt` (кнопки «Мои слова…» / «Не исправлять…» в настройках).
В настройках есть отдельная галочка «Исправлять опечатки» — если её снять, программа работает как раньше (только раскладка).
Словари загружаются в фоне при старте (1–2 с) и занимают около 50 МБ памяти.

## Сборка

```
dotnet test tests && dotnet publish src/App -c Release -o out && makensis installer/antiraskladka.nsi
```

Пересборка словарей (Linux): `sudo apt install hunspell-tools hunspell-ru hunspell-en-us && pip install wordfreq && python3 tools/build_dict.py`.
